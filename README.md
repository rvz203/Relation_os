# Relationship OS

Persian, RTL interactive interface prototype for personal relationship management.

Includes dashboard, people search, person detail sheet, relationship graph, Jalali calendar, actions and flower planning. Data is illustrative and kept in React state only. Reloading resets the demo. No real SMS, orders, contact transmission, authentication form or persistent contact storage is implemented.

Uses the bundled React/Vinext stack and existing accessible UI primitives. The site is privately hosted with Sites. Public application font: Vazirmatn.

## Development

Install using the Sites dependency helper and the committed pnpm lockfile. Use the managed Sites preview in supported environments. Build with the Sites build helper. Deployment identity is in `.openai/hosting.json`.
